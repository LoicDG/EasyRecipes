# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before
writing any code.

**v54, not the latest.** This project is pinned to SDK 54 (see CLAUDE.md for
why). APIs move between SDKs in both directions, so the current docs will lie to
you about this codebase: `expo-router/js-tabs` does not exist in 54, and
`File.copy()` is synchronous here but returns a promise in later SDKs.
